# Al3zba - تطبيق إدارة مصاريف السكن المشتركة (Arabic)

## 📖 مقدمة
تطبيق **Al3zba** هو تطبيق محلي لإدارة مصاريف سكن مشتركة (سكن طلابي أو عائلة) يدعم اللغة العربية بالكامل. يتيح لك:

- تعريف الأعضاء (البيت، منير، سالم، مجدي … أو أي أعضاء مخصصين).
- إضافة بنود الصرف مع تحديد المبلغ، من دفع، وطريقة التقسيم (متساوي للجميع، متساوي لبعض الأعضاء، أو مبالغ مخصصة).
- حساب حصة كل عضو تلقائيًا وعرض ملخص شامل للمدفوعات والصافي لكل عضو (له / عليه / خالص).
- توليد ملف PDF يطابق تمامًا نموذج الورقة التقليدي (مع خطوط عربية مدمجة).
- تصفير/حذف جميع البنود بنقرة واحدة ليستطيع المستخدم البدء من الصفر.
- مشاركة ملخص المصاريف عبر واتساب أو طباعة/معاينة الـ PDF.

> **ملاحظة**: جميع النصوص، القوائم، والواجهات مصممة بواجهة RTL لتتناسب مع اللغة العربية.

## 🛠️ المميزات الأساسية

| ميزة | الوصف |
|------|------|
| **إدارة الأعضاء** | إضافة، تعديل، حذف أعضاء من شاشة الإدارة. يدعم إضافة أي عدد من الأعضاء وتحديد إذا كان أحدهم “بيت”. |
| **إدخال بنود الصرف** | نافذة حوار لإضافة بند جديد مع اختيار **من دفع**، **طريقة التقسيم**، **مبلغ**، و**ملاحظة**. |
| **تقسيم مرن** | <ul><li>متساوي للجميع (`equalAll`).</li><li>متساوي لعدد مختار من الأعضاء (`equalSelected`).</li><li>مبالغ مخصصة لكل عضو (`customAmounts`).</li></ul> |
| **ملخص الأعضاء** | يظهر تلقائيًا حصة كل عضو، ما دفعه، وصافي ما عليه (له/عليه/خالص). |
| **توليد PDF** | إنشاء ملف PDF مطابق للنموذج التقليدي مع **خط RB Arabic** المتضمن في التطبيق. يدعم الطباعة أو المشاركة. |
| **إعادة ضبط** | زر **“تصفير وحذف جميع البنود”** يمسح جميع المصاريف ويعيد الصفر لتبدأ من جديد. |
| **دعم مشاركة واتساب** | زر مشاركة سريع يولد نصًا ملخصًا جاهزًا للإرسال. |
| **اختبارات آلية** | مجموعة اختبارات وحدة وويدجت تضمن استقرار الوظائف الأساسية. |
| **تخصيص الخطوط** | تحميل الخطوط `rb-bold.ttf`, `rb-light.ttf`, `rb-regular.ttf` من `assets/font/` وتعيينها كخط أساسي للتطبيق وتوليد الـ PDF. |

## 📚 دليل الاستخدام داخل التطبيق

### 1️⃣ إضافة أعضاء
*إذهب إلى القائمة → “إدارة الأعضاء”。*  
*أضف اسمًا، حدد ما إذا كان العضو “بيت”، احفظ.*

### 2️⃣ إضافة بند صرف
- اضغط على زر **إضافة بند صرف** (FAB) أو زر “إضافة بند صرف جديد” عند عدم وجود بنود.  
- ملء الحقول:
  - **العنوان** (مثلاً “الراشن”).
  - **المبلغ** (مثلاً `135000`).
  - **من دفع** (اختر عضوًا).  
  - **طريقة التقسيم** → **متساوي للجميع** / **متساوي لمختارين** / **مبالغ مخصصة**.
  - **الأعضاء المختارين** (فقط عند اختيار “متساوي لمختارين”).
  - **المبالغ المخصصة** (عند اختيار “مبالغ مخصصة”).

بعد الحفظ يتم حساب الحصص تلقائيًا وتحديث الواجهة.

### 3️⃣ مشاهدة ملخص الأعضاء
في الـ **HomeScreen** سترى جدولًا يضم كل بند، وحصة كل عضو، وتلخيصًا في أعلى الشاشة يوضح:

- **إجمالي المصاريف**.
- **حصة كل عضو**.
- **ما دفعه**.
- **الصافي** (له / عليه / خالص).

### 4️⃣ تصدير/معاينة PDF
- اضغط على أيقونة **طباعة** في شريط الأدوات.
- سيظهر **PdfPreviewScreen** حيث يمكنك معاينة الملف ثم طباعته أو مشاركته.
- الخط المستخدم هو **RB Arabic** لتظهر النصوص بشكل جذاب ومتسق.

### 5️⃣ مشاركة عبر واتساب
زر **مشاركة على واتساب** ينشئ نصًا ملخصًا (المجموع، حصة كل عضو، الفارق) جاهزًا للإرسال.

### 6️⃣ تصفير وحذف جميع البنود
اختر **“تصفير وحذف جميع البنود”** من القائمة العلوية أو من **PeriodSelectorSheet**. سيظهر **نوافذ تأكيد** لتفادي الخطأ، وبعد الموافقة تُصبح قائمة البنود فارغة وتظهر رسالة Snackbar:

> “تم تصفير وحذف جميع بنود الصرف بنجاح”

ثم يمكنك إضافة بنود جديدة من الصفر.

## 📈 معماري التطبيق

- **State Management**: `Provider` + `ChangeNotifier` (EzbaProvider).
- **Persistence**: `SharedPreferences` عبر `StorageService` (حفظ/تحميل JSON).
- **PDF Generation**: حزمة `pdf` + `printing`، مع تحميل الخط من `rootBundle`.
- **التصميم**: `Material 3` مع `ThemeData` يحدد `fontFamily: 'RB'` لتطبيق الخط على جميع الـ Widgets.
- **RTL Support**: تم ضبط `Directionality` إلى `rtl` في جميع الشاشات.
